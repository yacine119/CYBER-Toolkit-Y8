# Cyber Tool Kit

A simple website with useful **cybersecurity tools**, built with pure HTML, CSS, and JavaScript.

## Features
- Collection of cybersecurity tools
- Runs completely in the browser (client-side)
- Clean and responsive design

## How to Use
1. Open `index.html` in your browser
2. Select a tool and use it

Or run a local server:
```bash
python -m http.server 8000
```
Then go to `http://localhost:8000`

## Tech Stack
- HTML
- CSS
- JavaScript
